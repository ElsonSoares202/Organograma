# 🧩 Organograma em React

Este é um projeto desenvolvido em **React** que exibe um organograma interativo. Ideal para representar estruturas organizacionais de forma visual e clara.

## Tecnologias utilizadas

- React
- JavaScript
- HTML/CSS
